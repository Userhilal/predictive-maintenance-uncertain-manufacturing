# Validation policy — source files only

Do not create dummy machine measurements, simulated failure labels, generated images, fake repairs, artificial SCANIA vehicles, or synthetic test fixture records. The earlier fixture-based test scripts have been deleted.

Run actual-data validation tools against unchanged downloaded source files from the **three user-supplied links only**. Never report a test pass unless it was executed on actual available source data. SCANIA complete-file verification is pending until its original CSVs are accessible.

The original AI4I dataset is described as *synthetic* by its original Mendeley publisher; using the unmodified published observations is allowed under this policy, while creating extra synthetic records is not.
